# 展示会 名刺メモアプリ

名刺(表・裏)を撮影 + 話した内容を音声/テキストで入力 → Claudeが名刺OCR・要約・温度感判定・お礼メール文面生成 → スプレッドシート登録 + Gmail下書き作成。

```
スマホ(PWA: app/) --HTTPS--> Google Apps Script (gas/Code.gs) --> Claude API / Sheets / Gmail / Drive
```
APIキーはGASのスクリプトプロパティに保管され、端末には置きません。

## 機能
- 名刺の表裏撮影(裏は任意)、AIによる項目抽出
- 音声入力 / テキストメモ、商談の要約・次のアクション・温度感(高/中/低)
- お礼メールの文体設定: 丁寧さ(とても丁寧/標準/親しみやすい)、長さ、署名、追加指示
- **重複チェック**: メール一致、または氏名+会社名(全半角・「株式会社」表記ゆれ吸収)で既存行を検出 → 「既存の行に追記」or「別人として新規登録」
- **連続登録**: 登録後は自動で入力欄が空に。「保留して次へ」で撮り溜め(端末内IndexedDBに保存。電波が悪くてもOK)、後で読み込んで解析。本日の登録件数を表示
- 名刺画像はDriveの「名刺画像」フォルダに保存し、シートにリンクを記録

## シートの列(「名刺」シート。初回登録時に自動作成)
ID / 登録日時 / 展示会 / 温度感 / 氏名 / ふりがな / 会社名 / 部署・役職 / メール / 電話 / 住所 / URL / 商談要約 / 次のアクション / 話した内容(原文) / 名刺(表) / 名刺(裏) / 下書き / 対応状況 / 備考

温度感・対応状況(未対応/メール送信済/商談中/受注/見送り)はプルダウン。列の増減は `gas/Code.gs` 冒頭の `COLS` を編集します(`save_` の `appendRow` の並びも合わせる)。
既に旧レイアウトの「名刺」シートがある場合は、自動で「名刺_旧…」に名前変更して新規作成します。

## セットアップ

### 1. バックエンド(GAS)  約10分
1. 新しいGoogleスプレッドシートを作成 → 「拡張機能 > Apps Script」
2. `gas/Code.gs` の内容を貼り付けて保存
3. 左の歯車「プロジェクトの設定」→「スクリプトプロパティ」に追加
   - `CLAUDE_API_KEY` : AnthropicのAPIキー
   - `TOKEN` : 任意の長い合言葉(推測されにくいもの)
   - `SIGNATURE` : 既定の署名(任意。アプリ側の署名設定が優先)
4. エディタで関数 `authorize` を選び「実行」→ Gmail/Drive/外部通信の権限を承認
5. 「デプロイ > 新しいデプロイ > 種類:ウェブアプリ」→ 実行ユーザー=**自分**、アクセスできるユーザー=**全員** → URLをコピー
6. **コードを修正した場合**は「デプロイを管理 > 編集 > 新バージョン」で再デプロイ(URLは変わりません)

### 2. フロント(PWA)の公開先
どれも無料・HTTPS対応です(カメラ・音声入力・ホーム画面追加にHTTPSが必須)。

| 公開先 | おすすめ度 | 特徴 |
|---|---|---|
| **GitHub Pages** | ◎ 推奨 | 本リポジトリに設定済みworkflowあり。pushで自動更新 |
| Netlify | ○ | `app` フォルダをドラッグ&ドロップするだけ。最も手軽 |
| Cloudflare Pages | ○ | 高速。出力ディレクトリに `app` を指定 |

> 公開URLを知っている人は画面を開けますが、GAS URLと合言葉が無ければ何も登録できません。URL自体に秘密情報は含まれません。

#### A. GitHub Pages(推奨)
1. GitHubで新規リポジトリ(Privateでも可。ただしGitHub Pagesの非公開公開は有料プランのみ。無料ならPublic)を作成
2. このフォルダ一式をpush(`main` ブランチ)
   ```bash
   git init && git add . && git commit -m "init" && git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. リポジトリの Settings > Pages > Source を **GitHub Actions** に変更
4. Actionsタブで「Deploy PWA to GitHub Pages」が成功したら `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開URL

#### B. Netlify
https://app.netlify.com/drop に `app` フォルダをドラッグ&ドロップ → 発行されたURLが公開URL。

#### C. Cloudflare Pages
Pages > Create project > Direct Upload で `app` フォルダをアップロード。

### 3. スマホに入れる
- **iPhone**: Safariで公開URLを開く → 共有 → 「ホーム画面に追加」(音声入力・カメラはSafari/ホーム画面アプリで利用可)
- **Android**: Chromeで開く → メニュー → 「アプリをインストール / ホーム画面に追加」
- 初回は右上「設定」でGAS URL・合言葉・展示会名・署名を入力し、「接続テスト」で✅を確認 → 保存

## 使い方
1. 表面(必要なら裏面)を撮影
2. 話した内容を入力(🎤で音声)
3. 「AIで解析する」(混み合っているときは「保留して次へ」で先に次の方へ)
4. 内容・メール文面を確認して修正 → 「スプレッドシート登録 + Gmail下書き」
5. 重複候補が出たら「既存の行に追記」or「別人として新規登録」を選択
6. 展示会後、Gmailの下書きを確認して送信

## 注意・トラブル
- 名刺画像と商談メモはAnthropic APIに送信されます。社内の個人情報取り扱いルールを確認してください。
- メールアドレスが読み取れなかった場合は下書きを作らず、シート登録のみ行います(修正して再度入力すれば下書きが作られます)。
- 「GASの応答が不正です」→ デプロイのアクセス権が「全員」か、再デプロイ後のURLかを確認。
- 「Claude API エラー」→ `CLAUDE_API_KEY` と残高を確認。
- アプリを更新したのに古い画面が出る → 一度アプリを閉じて開き直す(Service Workerが更新されます)。
